# TEMPORARY, throwaway test file -- 2026-09-09, per the user's question
# "why can't we append rather than override [common/messages]?"
#
# Tests whether a SEPARATE, later-loaded file in common/messages/ can
# REDEFINE a message key that common/messages/00_messages.txt (our full
# vanilla copy) ALSO defines, and have this file's definition win --
# which would let us replace the entire 2300+-line full-copy override
# with a small ~30-50 line additive file, eliminating the patch-drift
# risk found earlier this session.
#
# Confirmed real: vanilla's own common/messages/ folder is split across
# 7 files, proving ADDITIVE-NEW-KEYS works. NOT confirmed either way:
# whether REDEFINING an existing key across files works, errors, or is
# silently ignored -- checked every vanilla message and law file, found
# zero cases of vanilla itself redefining an already-defined key, so
# there's no vanilla precedent to lean on. This file is the test.
#
# `country_attitude_improved` chosen because it fires very frequently
# (confirmed via this session's own debug.log investigation) and its
# values are maximally distinguishable: vanilla default is
# `notification_type = feed`, our own 00_messages.txt already retunes it
# to `none` (fully muted, Project 1). This file sets it to `popup`
# instead -- the most visually unmistakable possible outcome, so
# whichever value actually wins is obvious within minutes of play, no
# ambiguity.
#
# HOW TO READ THE RESULT:
#   - Full-screen popups for "X's attitude towards us improved" appear
#     -> this file's LATER-loaded redefinition won. Cross-file key
#     redefinition works -- the full-copy override can likely be
#     replaced with a small additive file.
#   - Nothing changes (still fully muted, matching 00_messages.txt) ->
#     the FIRST-loaded file's definition won, or duplicates are silently
#     ignored. Redefinition does NOT work this way -- keep the full copy.
#   - error.log shows a duplicate-definition warning/error -> redefining
#     across files is actively rejected. Also means: keep the full copy.
#
# DELETE this file (and revert 00_messages.txt if this proves
# redefinition works and a real refactor is done) once the result is
# observed -- it is not meant to ship.
country_attitude_improved = {
	type = country
	group = "country_attitude_changed_group"

	texture = "gfx/interface/icons/notification_icons/influence.dds"

	notification_type = popup
	color = neutral
}
