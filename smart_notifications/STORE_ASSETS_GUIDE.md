# Steam Workshop store assets — what's needed before publishing

This is a checklist for the visual assets Steam requires/expects for the
Workshop listing. None of these can be generated by an agent — they need
an actual play session with the mod's junction active (see
[[v3-mod-deployment]] / docs' own note on this: the mod is live-linked at
`Documents\Paradox Interactive\Victoria 3\mod\smart_notifications`, so any
of these can be captured any time the game is running with the mod
enabled in the launcher's playset).

## Before uploading: package a clean copy, don't upload the dev folder

The dev junction (`Documents\Paradox Interactive\Victoria 3\mod\smart_notifications`)
points at this whole repo — uploading from it directly would bundle
`tools/`, `docs/`, `reference/`, `.git/`, and every internal doc to
subscribers, since the Paradox Launcher packages the entire target
directory with no include/exclude filter. Run `python tools/package_release.py`
first (or `/package-release`) — it builds a clean copy (just
`.metadata/`, `common/`, `events/`, `gui/`, `localization/`,
`thumbnail.png`) at a *separate* mod folder,
`smart_notifications_release`, alongside the dev one. Add that as its own
entry in the launcher's Mod Library and upload from there — the dev
entry stays untouched and keeps reflecting live edits for testing. See
docs/engine-notes.md § Never upload the dev mod folder directly.

## Blocking: thumbnail.png

**Not currently present — this blocks upload.** Drop it at this repo's
root (`tools/package_release.py` will pick it up automatically from
there). The Paradox launcher-v2 mod format expects a `thumbnail.png` at
the mod's root (confirmed by
convention from the game's own DLC descriptors, e.g.
`game/dlc/dlc001_preorder/dlc001_preorder.dlc.json`'s `"thumbnailPath":
"thumbnail.png"` key — mods follow the same pattern). Exact accepted
pixel dimensions weren't found documented locally; the launcher's own
upload flow will reject/prompt if the file doesn't fit, so don't guess a
size — let the launcher tell you, or check the Paradox modding docs for
Victoria 3 specifically before cropping one. A square image, PNG, under
1MB, is the safe starting assumption other Paradox games use.

Suggested content: something that reads clearly at a small icon size
(the Workshop grid rescales it small) — e.g. a stylized bell/alert icon
over a Victoria 3-style parchment background, or a screenshot crop of the
Important Actions list showing 2-3 of this mod's own `(SN)` alerts
stacked together (the most visually distinctive, unique-to-this-mod
thing it adds).

## Screenshots (4-6, for the Workshop page body)

Steam accepts most reasonable resolutions and formats (PNG/JPEG); there's
no engine-side constraint here since these are just Workshop page media,
not game assets. 1920x1080 or your own desktop resolution is fine.
UI scale 100% keeps text legible in downscaled thumbnails. In order of
priority (do 1-3 at minimum; 4-6 are nice-to-have):

1. **Important Actions list with multiple `(SN)` alerts visible** — the
   single best "what does this mod actually do" shot. Trigger at least 2
   of: Agitator Invite Available, States with a Taxation Deficit
   (ideally showing the stacked-group count), Law Ready to Enact. This is
   the shot from the screenshot already captured during this session's
   testing (Portugal campaign, Jan 1885) — that one already shows all
   three at once and is a strong candidate as-is.

2. **Law Ready to Enact alert's tooltip open**, showing the specific law
   name and law group text (e.g. "Ready to enact: • Free Trade (Trade
   Policy)") — this is the feature that took the most iterations to get
   right and is worth showing off specifically, since it's not obvious
   from the alert icon alone that it names the exact law.

3. **The law detail panel's opt-in checkbox** (`(SN) Alert me when I can
   pass this`), in Politics → Laws → any law's detail view — shows the
   mod's actual UI footprint, not just notification behavior.

4. **Message Settings screen**, scrolled to where the `(SN)`-tagged rows
   are, demonstrating the notification-tuning half of the mod (the
   original Phase 1 feature) and that custom entries are clearly
   distinguishable from vanilla ones.

5. *(Optional)* A relational-watchlist moment — a diplomatic
   play/war-start notification firing specifically because a Watchlist
   country is involved. Harder to stage on demand since it depends on AI
   behavior; skip if not naturally available before the beta.

6. *(Optional)* Before/after comparison of a muted vanilla notification
   (e.g. a demoted feed-tier item) vs. its previous toast-tier vanilla
   behavior — conceptually useful but hard to actually screenshot side by
   side in one client; a text callout over a single screenshot may work
   better than a real comparison shot.

## Not needed for a private/beta listing

Trailers, localized screenshots, and a curated "featured" image are all
optional extras for a public, promoted listing — skip all of them for a
private beta. Steam's "friends-only"/"unlisted" visibility (set at
upload time in the launcher's Mod Tools) doesn't require any of the
polish a public front-page listing would.
